## 1. このフォルダで何ができるか

このフォルダには、藤田様送付の **マスタ 145 社** の必要書類 (8 種) の受領状況・原本 PDF・突合せ情報がまとまっています。

主な用途:

- **新規/継続取引の審査**: 8 種の書類が揃っているか一目で確認
- **書類の閲覧**: 受領済 PDF を Explorer から直接開く
- **不足書類の督促**: △ (一部受領) や × (未受領) の社を抽出して督促
- **建設業許可証の期限管理**: Webアプリ (GAS) のダッシュボードで期限切迫順に確認

## 2. ダウンロード後の手順

## 5. 業務フロー

### 5.1 新規/継続取引の審査

1. `00_一覧表_v2_20260427.xlsx` を開く
2. シート 1 で該当社を検索 (Ctrl+F)
3. **審査可 = ◎** なら → `10_originals/C0XXX_<会社名>/` で原本 PDF を確認
4. **審査可 = △ or ×** なら → 不足書類を督促

### 5.2 書類が見つからないとき

1. 一覧表の **会社ID 列 (C0XXX)** を確認
2. Explorer で `10_originals/` を開き、`C0XXX_*` フォルダを探す
3. 各書類カテゴリフォルダ (01_取引申請書 〜 08_労働者名簿) を確認
4. それでも見つからない場合は **`99_受領バンドル/`** を確認 (複数書類が混在した PDF)

### 5.3 不足書類の督促リスト作成

Excel 一覧表のフィルタ機能で:

- **× 未受領** (38 社) を抽出 → 督促対象 (DB登録ありで書類が来ていない)
- **△ 一部受領** (43 社) を抽出 → 不足書類のみ督促 (○/× 列で不足を特定)
- **当方未登録** (25 社) を抽出 → そもそも一度も書類が届いていない、優先督促

### 5.4 建設業許可証の期限管理 (Webアプリ)

期限切迫順の管理は **Webアプリ (GAS ダッシュボード)** で行います。

- **WebアプリURL**: https://script.google.com/macros/s/AKfycbwYJIHfhZ6HBzfNlv2MRl1H3ZqaVMzYBv9KOIMebrQGJ5ftAl3rNymX1KmjjtVtagn1/exec
- **データソース**: Google Sheets (52 社の許可情報、MLIT 自動連携)
- **更新頻度**: 毎日 02:00 JST に MLIT (国土交通省) から自動更新
- **表示**: 残日数の少ない順 (期限切迫順) でソート

#### Webアプリでできること

- 各社の建設業許可証の **種類** (業種、般特、許可番号) を確認
- **有効期限** と **残日数** をリアルタイムに把握
- 期限切迫社の絞り込み
- ※ ダッシュボードに表示されるのは **MLITPermits シートに登録済の 52 社のみ** (許可証必要社のみ管理する運用方針)

## 6. 数字の見方 (補足)

### 6.1 「マスタ 145 社」と「当方 DB 142 社」の関係

- **マスタ 145 社**: 藤田様送付の正本リスト (`145社_許可一覧.xlsx`)
- **当方 DB 142 社**: 当方が記録している社 (rename・統合・幽霊レコード除去後)
- 差分は **突合せレポート** で透明化:
  - マスタにあって DB にない: 25 社 (督促候補)
  - DB にあってマスタにない: 22 社 (過去取引・統合済、本一覧表からは除外)

### 6.2 「◎ 39 + △ 43 + × 38 + 未登録 25 = 145」の意味

- ◎ 39 社: 8 種すべて揃い → 即審査可
- △ 43 社: 1〜7 種受領 → 不足分を督促
- × 38 社: DB 登録あり書類なし → 全書類督促
- 未登録 25 社: マスタにあるが当方未受信 → 連絡先確認 + 督促
