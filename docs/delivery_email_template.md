# 藤田さん宛 納品メール下書きテンプレ

## 使い方

藤田さんからの元メールを Gmail で開いて「**返信**」、本文を以下で置き換える。
`{{...}}` の部分は実際の値に差し替え。

---

## 件名（自動継承）

`Re: 新規・継続取引契約書につきまして` (元スレッドの件名がそのまま付く)

## 本文

```
藤田 様

お世話になっております。

ご依頼いただいておりました協力会社 145 社（マスタ）の必要書類について、
現時点で受領済みの分を取りまとめましたのでご連絡いたします。

■ 納品物
  Google Drive 共有リンク: {{ここに共有リンクを貼る}}
  ファイル名: FDE_MANAGED_20260426.zip
  サイズ: 約 314 MB
  ファイル数: 234（README + 一覧表 + 突合せレポート + 230 PDF）

■ 内訳（当方 DB 142 社中）
  ・受領済み会社: 91 社（フォルダあり）
  ・全書類揃い: 37 社（◎）
  ・一部受信: 32 社（△）
  ・未受信: 73 社（書類なし、フォルダなし）

■ ZIP 内容
  ・00_一覧表_20260426.xlsx — 142 社の揃い具合一覧
  ・00_突合せレポート_20260426.xlsx — マスタ 145 社 vs 当方 DB 142 社の差分
  ・10_originals/C0XXX_<会社名>/<書類カテゴリ>/<受領年>/ — 原本 PDF
  ・99_受領バンドル/ — 複数書類が混在しているもの（要振分）
  ・README_運用規程.txt — フォルダ構成の説明
  ・manifest_sha256.txt — 全ファイルのハッシュ（改ざん検知用）

■ 補足
  ・原本ファイル名は受領時のまま（リネームしておりません）
  ・「99_受領バンドル」内は OCR で書類種別判定が難しかったものです
  ・未受信 73 社の督促リストが必要でしたら別途お送りします
  ・マスタ 145 社 vs 当方 DB 142 社の差は表記揺れ含めて約 30 社あります。
    詳細は突合せレポートをご確認のうえ、追加すべき会社があればお知らせください

ご確認のほどよろしくお願い申し上げます。

{{送信者署名}}
```

---

## 送信前チェックリスト

- [ ] 共有リンクを貼った
- [ ] リンクが「閲覧者」権限になっている（編集権限になっていない）
- [ ] CC に必要な人を追加した（社内チーム等）
- [ ] 添付ファイルとして ZIP を直接添付していない（Drive リンク経由のみ）
- [ ] 元スレッドへの「返信」になっている（新規メール作成になっていない）

## バリエーション

### 月次の追加納品の場合

```
■ 納品物（{{月}}月分追加）
  前回（{{前回月}}）以降の新規受領分を含めた最新版です。
  Google Drive 共有リンク: {{リンク}}
  
■ 前回からの差分
  ・新規受領: {{N}} 社
  ・追加書類: {{M}} 件
  
（以下、本文同じ）
```

### 緊急性が高い場合

冒頭に追加:
```
※ 期限が迫っている案件のため、ご確認お願いいたします。
※ ご質問があればお手数ですが本メールにご返信ください。
```
