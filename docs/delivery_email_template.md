# 藤田さん宛 納品メール下書きテンプレ

## 使い方

藤田さんからの元メールを Gmail で開いて「**返信**」、本文を以下で置き換える。
`{{...}}` の部分は実際の値に差し替え。

---

## 件名（自動継承）

`Re: 新規・継続取引契約書につきまして` (元スレッドの件名がそのまま付く)

## 送信前チェックリスト

- [ ] 共有リンクを貼った
- [ ] リンクが「閲覧者」権限になっている（編集権限になっていない）
- [ ] CC に必要な人を追加した（社内チーム等）
- [ ] 添付ファイルとして ZIP を直接添付していない（Drive リンク経由のみ）
- [ ] 元スレッドへの「返信」になっている（新規メール作成になっていない）
- [ ] 数字: マスタ145 / ◎39 / △31 / ×50 / 未登録25 / ZIP約315MB が v2 一覧表と一致
      （`python scripts/generate_review_list_v2.py` で再確認可能）
- [ ] ZIP ファイル名が `FDE_MANAGED_20260427.zip` になっている
