# 担当者編集ワークシート ご使用方法

藤田 様

`06_担当者編集_<TS>_<workflow_id>.xlsx` の使い方をご案内します。

---

## 全体構成 (7 シート)

| シート | 用途 | 編集 |
|---|---|---|
| `0_workflow_meta` | 機械処理用メタ情報 | **編集禁止** |
| `1_突合せ確認` | 会社名表記ゆれの同定 | 黄色列のみ |
| `2_受領状況編集` | ○/× の修正・反映依頼 | 黄色列のみ |
| `3_期限管理` | 許可証期限の対応状況 | 黄色列のみ |
| `4_新規候補` | 藤田様マスタのみ記載の社 | 黄色列のみ |
| `5_既存対象外化候補` | 当方 ACTIVE → 対象外化 | 黄色列のみ |
| `6_揃いvs有効_並列` | 当方/藤田様の判定対比 (参照のみ) | 編集なし |

---

## 編集ルール (シンプル 3 原則)

1. **黄色背景の列だけ編集してください** (灰色は機械処理用なので変更しないでください)
2. **判定列は必ずドロップダウンから選択してください** (自由入力するとエラーになります)
3. **行の追加・削除はしないでください** (新規追加は別途お知らせください)

---

## シート別の編集手順

### `1_突合せ確認`
当方で会社名突合せがうまくいかなかった社の一覧です。

- **判定** ドロップダウン:
  - `同一` … 当方 `推定company_id` の社と同じです
  - `別社` … 別の会社です
  - `新規候補` … 藤田様マスタの新規追加です
  - `保留` … 判断保留 (理由をコメント欄に)

例: `Ｇテリア (全角)` ↔ 当方 `Gテリア (半角)` のような表記揺れに `同一` を選択。

### `2_受領状況編集` (主作業画面)
藤田様の修正依頼コメントを反映する画面です。

- **担当者判断** ドロップダウン:
  - `反映` … この修正を当方データに反映してください
  - `保留` … 後で再検討
  - `却下` … 反映しない (理由をコメント欄に)
- **反映後の値**: `○ / × / 対象外 / -`
- **分類**:
  - `受領済` … 既に書類を受領
  - `対象外` … この書類は不要
  - `代替資料で可` … 別資料で代替済
  - `要再依頼` … 先方に再度依頼が必要
  - `確認中` … 状況確認中

例: 「労働者名簿: P18 に添付あり」と藤田様が書かれた行 → `反映` + `○` + `代替資料で可` を選択。

### `3_期限管理`
許可証期限が切れた / 90日以内の社の対応状況。

- **期限ステータス**:
  - `MLIT更新確認済` … 国交省サイトで更新確認済 (新期限を `次アクション期日` に記入)
  - `藤田に再依頼` … 添付許可証の差替えを依頼
  - `期限切れ確定` … 真に期限切れ
  - `督促済` … 督促連絡済

### `4_新規候補`
藤田様マスタにあって当方マスタに存在しない社。

- **処理**:
  - `候補確定` … 当方マスタに追加候補とする (この時点では DB に直接追加されません、staging 保留)
  - `別名疑い` … 既存社の別表記の可能性 (どの社かをコメントに)
  - `対象外候補` … 管理対象外

### `5_既存対象外化候補`
当方 ACTIVE 管理中だが、藤田様が「対象外」と判定された社。

- **処理**:
  - `INACTIVE化` … 当方マスタから INACTIVE 化 (履歴は残ります)
  - `対象外フラグ` … 管理対象外フラグを立てる
  - `維持` … 当方 ACTIVE のまま維持
- **理由**: `取引終了 / 廃業 / 重複 / その他`

---

## 完了後

編集が終わりましたら、ファイルをそのまま当方にお戻しください。
当方で内容を読み取り、`一覧表 v3` と DB に反映いたします。

**注意**: ファイル名 (workflow_id) を変更しないでください。
変更すると当方の二重反映防止チェックが効かなくなります。

---

## ご質問・トラブル

- 列を間違って編集してしまった場合: `Ctrl+Z` で取り消すか、当方にご連絡ください
- ドロップダウンが効かない場合: 該当セルを右クリック → 「データの入力規則」をご確認ください
- ファイルが開けない場合: Excel 2016 以降が必要です

ご不明点があればお気軽にお問合せください。
